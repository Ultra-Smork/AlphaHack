# Суирники3

B2C-кредитный симулятор на базе ИИ. Предприниматель заполняет заявку, нейросеть оценивает бизнес и выдаёт предложение.

## Запуск

```bash
make install
make dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:8000

Один контейнер, backend + frontend:

```bash
docker compose up --build
```

Приложение: http://localhost:8000

Проверка:

```bash
make check
```

Полный сброс локальной БД и seed:

```bash
make reset-db
```

## Демо-аккаунт

```text
client@demo.ru / password123
```

## Демо за 3 минуты

1. Войти под `client@demo.ru`.
2. Открыть **#4** — финальный `OFFER_ACCEPTED`.
3. Открыть **#3** — `OFFER_MADE`, counteroffer: движок снизил сумму.
4. Открыть **#2** — `NEEDS_INFO`, показать недостающие поля.
5. Открыть **#1** — `REJECTED`, показать risk score и факторы.
6. Создать новую заявку — показать форму и валидацию.
7. Подать заявку — показать polling «Нейросеть оценивает ваш бизнес...».
8. Вернуться к списку — показать статистику и фильтры.

## Демо-данные

Seed создаёт четыре заявки:

- `#1` — `REJECTED`, high risk, 1 000 000 ₽, 24 месяца.
- `#2` — `NEEDS_INFO`, не хватает финансовых данных.
- `#3` — `OFFER_MADE`, запрошено 5 000 000 ₽, engine дал counteroffer 1 630 000 ₽ под 23%.
- `#4` — `OFFER_ACCEPTED`, 1 000 000 ₽, 24 месяца, 24%.

Список сортируется по id DESC, поэтому сверху видны `#4`, `#3`, `#2`, `#1`.

Seed идемпотентный: повторный запуск не создаёт дубликаты.
